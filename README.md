# مكتبة فتاوى الشيخ مصطفى العدوي

تطبيق ويب عربي (RTL) لنشر الفتاوى وتصنيفها، مع بحث بالذكاء الاصطناعي، وتسجيل صوتي لكل فتوى،
ورقم ورابط مستقل لكل فتوى، ولوحة تحكم كاملة لإدارة المحتوى.

## الخصائص

| الخاصية | المسار | ملاحظات |
| --- | --- | --- |
| 🔎 البحث بالذكاء الاصطناعي | `/search` | استرجاع نصي عربي ثم إعادة ترتيب وتلخيص عبر Claude |
| 🗂️ تصنيف الفتاوى | `/categories` و `/categories/[slug]` | أبواب فقهية قابلة للإدارة |
| 📄 صفحة الفتوى | `/fatwas/[رقم]` | السؤال، الإجابة، التسجيل الصوتي، حفظ، مشاركة، نسخ |
| 👤 الصفحة الشخصية | `/saved` | الفتاوى المحفوظة على الجهاز |
| 🔗 رابط مستقل لكل فتوى | `/fatwas/1001` و `/f/1001` | رقم فريد لكل فتوى وهو أساس الرابط |
| 👨‍🏫 نبذة عن الشيخ | `/sheikh` | تعريف مختصر وكامل قابل للتحرير |
| 📚 مؤلفات الشيخ | `/books` | أسماء الكتب مع نبذة وبيانات النشر |
| ⚙️ لوحة التحكم | `/admin` | إدارة الفتاوى والتصنيفات والتسجيلات والمؤلفات والنبذة والأرقام والروابط |

### تفاصيل الحفظ في «الصفحة الشخصية»

الحفظ يتم في متصفح الزائر (`localStorage`) بلا تسجيل دخول — لأن الطلب لم يتضمن نظام حسابات.
النتيجة: قائمة المحفوظات خاصة بكل جهاز ولا تنتقل بين الأجهزة. إن أردت لاحقًا مزامنة المحفوظات
بين الأجهزة فسيلزم إضافة تسجيل دخول للزوار.

## التشغيل

```bash
npm install
cp .env.example .env.local   # ثم عدّل القيم
npm run dev                  # التطوير على http://localhost:3000
```

للإنتاج:

```bash
npm run build
npm run start
```

### متغيرات البيئة

| المتغير | الوصف |
| --- | --- |
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم. **مطلوبة قبل النشر** (بدونها تُستخدم كلمة مرور تطوير افتراضية `admin` مع تحذير في اللوحة). |
| `ADMIN_SESSION_SECRET` | نص عشوائي طويل لتوقيع كوكي الجلسة. |
| `ANTHROPIC_API_KEY` | يفعّل البحث بالذكاء الاصطناعي. بدونه يعمل البحث النصي فقط. |
| `FATAWA_DB_PATH` | مسار ملف قاعدة البيانات (الافتراضي `./data/fatawa.db`). |
| `UPLOADS_DIR` | مجلد التسجيلات المرفوعة (الافتراضي `./data/uploads`). |

## البنية التقنية

- **Next.js 16** (App Router، خادم React Components، Server Actions) و**React 19** و**TypeScript**.
- **Tailwind CSS 4** مع سمة عربية RTL وخط Cairo، ودعم الوضع الليلي تلقائيًا.
- **SQLite** عبر `better-sqlite3`، وقاعدة البيانات تُنشأ وتُبذَر تلقائيًا عند أول تشغيل.
- **FTS5** لفهرس بحث نصي على نص عربي مطبَّع (بلا تشكيل، وبتوحيد الألف والياء والتاء المربوطة).
- **Claude** (`claude-opus-5`) لإعادة ترتيب نتائج البحث وتلخيصها.

### كيف يعمل البحث

1. تطبيع الاستعلام العربي وتقطيعه (`lib/arabic.ts`).
2. استرجاع أولي من فهرس FTS5 بترتيب `bm25`، مع تدرّج: كل الكلمات ← أي كلمة ← مطابقة جزئية.
   والبحث برقم الفتوى يعيد الفتوى مباشرة.
3. عند توفر `ANTHROPIC_API_KEY`: تُرسل الفتاوى المرشّحة إلى Claude ليختار المرتبط بالسؤال
   ويرتّبه ويكتب ملخصًا **من نصوص الفتاوى نفسها فقط** — مع منع صريح في التعليمات من الإفتاء
   أو إضافة حكم غير موجود.
4. عند غياب المفتاح أو تعذّر الاتصال أو رفض النموذج: يعود البحث النصي مع تنويه للزائر.

## المحتوى الأولي — مهم

قاعدة البيانات تُبذَر عند أول تشغيل بـ **أمثلة توضيحية** لبنية الفتاوى والتصنيفات، وهي ليست نقلًا
موثّقًا عن الشيخ، ومكتوب في حقل المصدر لكل منها أنها مثال يُستبدل. كذلك النبذة وقائمة المؤلفات
مبدئية وتحتاج تدقيقًا. استبدل هذا كله من لوحة التحكم بالفتاوى الموثّقة قبل النشر.

## النشر

التطبيق يحتاج خادم Node.js دائم (لا يعمل على بيئة بلا نظام ملفات قابل للكتابة) لأن قاعدة
البيانات SQLite والتسجيلات المرفوعة تُخزَّن على القرص. عند النشر على منصة بلا تخزين دائم
(مثل بيئات serverless) استخدم قاعدة بيانات مُدارة وروابط صوتية خارجية بدل الرفع المحلي.

## مخطط قاعدة البيانات

- `fatwas` — الفتوى: `number` (فريد) و`slug` و`title` و`question` و`answer` و`audio_url`
  و`category_id` و`published` و`views`.
- `fatwas_fts` — فهرس FTS5 للنص المطبَّع.
- `categories` — التصنيفات.
- `books` — المؤلفات.
- `settings` — نبذة الشيخ وإعدادات الموقع (مفتاح/قيمة).
