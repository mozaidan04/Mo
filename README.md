# مكتبة فتاوى الشيخ مصطفى العدوي

تطبيق ويب عربي (RTL) لنشر الفتاوى وتصنيفها، مع بحث بالذكاء الاصطناعي، وتسجيل صوتي لكل فتوى،
ورقم ورابط مستقل لكل فتوى، وحسابات للزوار، ولوحة تحكم لإدارة المحتوى.

## الخصائص

| الخاصية | المسار | ملاحظات |
| --- | --- | --- |
| 🔎 البحث بالذكاء الاصطناعي | `/search` | بحث نصي عربي في Postgres ثم إعادة ترتيب وتلخيص عبر Claude |
| 🗂️ تصنيف الفتاوى | `/categories` و `/categories/[slug]` | أبواب فقهية قابلة للإدارة |
| 📄 صفحة الفتوى | `/fatwas/[رقم]` | السؤال، الإجابة، التسجيل الصوتي، حفظ، مشاركة، نسخ |
| 👤 تسجيل الدخول | `/login` | بالبريد وكلمة المرور (Supabase Auth) |
| 👤 الصفحة الشخصية | `/saved` | الفتاوى المحفوظة في الحساب، تظهر على كل الأجهزة |
| 🔗 رابط مستقل لكل فتوى | `/fatwas/1001` و `/f/1001` | رقم فريد لكل فتوى وهو أساس الرابط |
| 👨‍🏫 نبذة عن الشيخ | `/sheikh` | تعريف مختصر وكامل قابل للتحرير |
| 📚 مؤلفات الشيخ | `/books` | أسماء الكتب مع نبذة وبيانات النشر |
| ⚙️ لوحة التحكم | `/admin` | الفتاوى والتصنيفات والتسجيلات والمؤلفات والنبذة والأرقام والروابط |

## البنية التقنية

- **Next.js 16** (App Router، Server Components، Server Actions) و**React 19** و**TypeScript**.
- **Tailwind CSS 4** بسمة عربية RTL وخط Cairo، مع دعم الوضع الليلي.
- **Supabase**: Postgres للبيانات، وAuth لتسجيل الدخول، وStorage للتسجيلات الصوتية.
- **Claude** (`claude-opus-5`) لإعادة ترتيب نتائج البحث وتلخيصها.

### الحماية: كل شيء محكوم بـ RLS

المفتاح المستخدم في المتصفح مفتاح عام (publishable)، والحماية الحقيقية في قاعدة البيانات
عبر سياسات Row Level Security:

- الفتاوى المنشورة والتصنيفات والمؤلفات والإعدادات: **قراءة للجميع**.
- الفتاوى غير المنشورة وكل عمليات الكتابة: **للمشرف فقط**.
- الفتاوى المحفوظة: كل مستخدم يرى ويعدّل صفوفه هو فقط.
- جدول `admins`: لا يقرؤه إلا مشرف، فبريد المشرف غير مكشوف لأحد.

### من هو المشرف؟

المشرف هو صاحب البريد المُدرج في جدول `admins` داخل قاعدة البيانات — وهذا هو المصدر
الوحيد للصلاحية، لأن سياسات RLS في القاعدة هي ما يمنع الكتابة فعليًا.
الدخول يتم بحساب عادي، والموقع يفتح لوحة التحكم إذا كان بريد الحساب مُدرجًا.

لإضافة مشرف آخر، نفّذ في محرر SQL بلوحة Supabase:

```sql
insert into public.admins (email, note) values ('someone@example.com', 'مشرف إضافي');
```

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # ثم ضع قيم مشروعك من Supabase
npm run dev
```

### متغيرات البيئة

| المتغير | الوصف |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | رابط مشروع Supabase. **مطلوب** |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | المفتاح العام (publishable). **مطلوب** |
| `ANTHROPIC_API_KEY` | يفعّل البحث بالذكاء الاصطناعي. بدونه يعمل البحث النصي وحده. |

## قاعدة البيانات

الجداول: `fatwas`, `categories`, `books`, `settings`, `admins`, `saved_fatwas`.
والدوال: `normalize_ar` (تطبيع النص العربي)، `search_fatwas` (البحث)،
`increment_fatwa_views` (عدّاد المشاهدات)، `is_admin` (صلاحية الإدارة).
ملف `supabase/seed.sql` يحتوي بيانات البداية كما رُفعت.

### كيف يعمل البحث

1. تطبيع النص داخل Postgres: إزالة التشكيل والتطويل، وتوحيد الألف والياء والتاء المربوطة،
   وتحويل الأرقام العربية — عبر الدالة `normalize_ar` المستخدمة في فهرس `tsvector` مولَّد تلقائيًا.
2. مطابقة full-text مرتّبة بـ `ts_rank_cd` بأوزان (العنوان ثم الوسوم ثم السؤال ثم الإجابة)،
   مع تدرّج: الكلمات الدالّة ← كل الكلمات ← مطابقة تقريبية (trigram) للأخطاء الإملائية.
   والبحث برقم الفتوى يعيدها مباشرة.
3. عند توفر `ANTHROPIC_API_KEY`: تُرسل الفتاوى المرشّحة إلى Claude ليختار المرتبط بالسؤال
   ويرتّبه ويكتب ملخصًا **من نصوص الفتاوى نفسها فقط** — مع منع صريح من الإفتاء أو إضافة حكم.
4. عند غياب المفتاح أو تعذّر الاتصال أو رفض النموذج: يعود البحث النصي مع تنويه للزائر.

## إعدادات Supabase المطلوبة

1. **تسجيل الدخول بالبريد**: مفعّل افتراضيًا. إن أردت أن يدخل المستخدم فور التسجيل بلا رسالة
   تأكيد، عطّل *Confirm email* من: Authentication → Sign In / Providers → Email.
   (خدمة البريد الافتراضية في Supabase محدودة جدًا؛ لإرسال رسائل تأكيد حقيقية اربط خادم SMTP.)
2. **جوجل وفيسبوك**: غير مفعّلين حاليًا. لتفعيل أيٍّ منهما لاحقًا: أنشئ تطبيقًا لدى المزوّد،
   ضع `Client ID` و`Client Secret` في Authentication → Providers، ثم أضف زر الدخول في
   `components/auth-form.tsx` عبر `supabase.auth.signInWithOAuth({ provider: "google" })`.
3. **مخزن الصوتيات**: مخزن `fatwa-audio` مُنشأ بقراءة عامة ورفع للمشرف فقط.

## النشر على Vercel

المشروع لا يحتاج نظام ملفات قابلًا للكتابة (كل شيء في Supabase)، فيعمل على Vercel مباشرة.

- قيم Supabase العامة موجودة في `.env.production` المرفوع مع الكود، فالموقع يعمل بعد النشر
  مباشرة دون إعداد إضافي.
- لتفعيل البحث بالذكاء الاصطناعي أضف `ANTHROPIC_API_KEY` في:
  Vercel → Project → Settings → Environment Variables، ثم أعد النشر.
- فرع الإنتاج هو `claude/fatwa-library-al-adawi-mnx4lo` (وهو الفرع الافتراضي للمستودع)،
  فكل دفعة إليه تُنتج نشرًا جديدًا تلقائيًا.

## المحتوى الأولي — مهم

قاعدة البيانات مبذورة بـ **أمثلة توضيحية** لبنية الفتاوى والتصنيفات، وهي ليست نقلًا موثّقًا
عن الشيخ، ومكتوب في حقل المصدر لكل منها أنها مثال يُستبدل. كذلك النبذة وقائمة المؤلفات
مبدئية وتحتاج تدقيقًا. استبدل هذا كله من لوحة التحكم قبل النشر للناس.
